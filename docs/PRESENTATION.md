# DataForge — registre de données

## Présentation
dataforge est un registre immuable, hashé et auditable.

## À quoi ça sert ?
Versionne, lineage et atteste l'intégrité des jeux de données.

## Cas d'usages concrets
- Pipeline data, audit RGPD, dataset ML

## À quoi ça pourrait servir (futur)
- Data mesh, traçabilité alimentaire, open data certifié
